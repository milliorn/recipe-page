# Changelog

All notable changes to this project will be documented in this file. Entries from the next release onward are generated by [release-please](https://github.com/googleapis/release-please) from Conventional Commits; see [CONTRIBUTING.md](CONTRIBUTING.md) for commit message guidelines. The 0.1.1-0.1.3 entries were generated by `standard-version`, a tool this project no longer uses; entries before 0.1.1 predate that tool and are hand-summarized from commit history instead.

### Unreleased history (2021-2026)

Grouped by activity rather than by individual commit, since most commit messages from this era were free-form (e.g. "lint", "deps", "navbar") rather than typed.

- **Oct-Dec 2021** - Initial build-out: Gatsby scaffold, recipe/tag/about/contact/404 pages, Navbar/Footer/Layout components, Contentful integration, global CSS, early CI workflow experimentation.
- **Jan-Apr 2022** - CI cleanup: removed several short-lived GitHub Action workflows, general refactor (#157).
- **Jan-Jul 2023** - Dependency-tooling churn: cycled through dependency-review, combine-prs, Renovate, Dependabot, and several security-scanning workflows (CodeQL, DevSkim, OSSAR, super-linter) added then removed.
- **Jan-Feb 2024** - Larger refactor pass: SiteSeo/RandomQuote components, GraphQL query simplification, Netlify adapter added, styling/typography overhaul, license updated to MIT.
- **Apr-Dec 2025** - Periodic maintenance: LCP/CLS performance fixes, two seasonal update passes, lockfile updates, automerge/Dependabot config tweaks.
